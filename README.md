# وب‌لاگ زرتسترا (React + Vite)

وب‌لاگ شخصی فارسی و راست‌به‌چپ. همهٔ نوشته‌ها، عکس‌ها و ویدیوها از خروجی تلگرامِ کانال «زرتسترا» (`https://t.me/sanmartin1378`) آمده‌اند.

## آدرس عمومی

نسخهٔ زنده: https://akabiri3900.github.io/blog/

سایت از شاخهٔ `gh-pages` همین مخزن روی GitHub Pages سرو می‌شود و کد منبع روی `main` است. برای به‌روزرسانی، بعد از `npm run build` محتوای پوشهٔ `dist` را (به‌علاوهٔ یک فایل خالی `.nojekyll`) روی شاخهٔ `gh-pages` بفرستید. فایل `404.html` لازم است تا ورود مستقیم به آدرس‌هایی مثل `/blog/post/...` کار کند.

## اجرا

```bash
npm install
npm run dev
```

بعد `http://127.0.0.1:5176` را باز کنید. برای نسخهٔ نهایی:

```bash
npm run build
npm run preview
```

## به‌روزرسانی با پست‌های تازه

1. در Telegram Desktop، داخل کانال، منوی سه‌نقطه ← **Export chat history** ← فرمت **HTML** (عکس و ویدیو را هم تیک بزنید).
2. این دستور را با مسیر پوشهٔ خروجی بزنید:

```bash
npm run import -- "D:\claud\ChatExport_2026-10-04"
```

اسکریپت `scripts/import-telegram.mjs` فایل‌های `src/posts.json` و `public/media/` را از نو می‌سازد.

### اسکریپت چه می‌کند

- متن پست‌ها را دست‌نخورده نگه می‌دارد. فقط قالب‌بندی (پررنگ، کج، لینک) و شکستن پاراگراف‌ها حفظ می‌شود و HTML خطرناک حذف می‌شود.
- دو پیامِ هم‌ثانیه (تلگرام متن بلند را دو تکه می‌کند) را یک پست می‌کند.
- اگر خط اول پست کوتاه (تا ۹۰ حرف) و بقیهٔ متن بلند باشد، همان خط را عنوان نشان می‌دهد. برای پست‌های بی‌عنوان عنوان نمی‌سازد.
- برچسب‌ها را از نوع محتوا می‌سازد: «جستار» (متن بلند)، «قطعه»، «عکس»، «ویدیو»، «موسیقی» و «بازنشر».
- فایل صوتی در خروجی تلگرام نیست («Not included»)، پس برای آهنگ‌ها فقط نام و لینک می‌ماند.

## ساختار

- `src/data.js`: خواندن `posts.json`، جست‌وجو، برچسب‌ها و متن جایگزین تصویرها (`ALT`).
- `src/pages/`: صفحهٔ اصلی، بایگانی (جست‌وجو و فیلتر)، صفحهٔ نوشته و دربارهٔ وب‌لاگ.
- `src/router.jsx`: مسیریاب کوچک با History API و پردهٔ بین صفحه‌ها.
- `src/styles.css`: همهٔ استایل‌ها و حرکت‌ها. حرکت‌ها با «کاهش حرکت» سیستم خاموش می‌شوند.
- `public/media/`: عکس‌ها و ویدیوهای واردشده.

## نکته‌ها

- متن جایگزین عکس‌ها در `src/data.js` است. برای عکس تازه یک ردیف به `ALT` اضافه کنید.
- ویدیوها فقط وقتی کاربر پخش را بزند بارگیری می‌شوند.
- فونت وزیرمتن از Google Fonts بارگذاری می‌شود.
